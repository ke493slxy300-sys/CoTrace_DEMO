# CoTrace 队友节点内容包

本内容包用于演示队友节点详情中的实际成果、片段式 AI 溯源卡片和项目理解 Agent 工作日志。

## 演示角色

- 队友 A：前端页面
- 队友 B：数据库设计与实现
- 队友 C：用户需求与分析
- Maya Chen：项目负责人、后端 API 负责人

队友 A、B、C 只是演示代号，不代表最终项目成员。页面应根据项目注册时实际选择的协作者和职责动态替换负责人名称、头像和成员 ID。

## 内容边界

- 不包含队友的完整原始 Agent 对话。
- 溯源卡片只保留当前队友主动选择的短片段，并由项目理解 Agent 按任务主题整合。
- 代码和文档是节点演示内容，不附加“已经提交”状态。
- 团队讨论仍是次级窗口，本包不生成讨论正文。
- Maya 部分只整理上一阶段已有协作记录，不重复制造另一套原始对话。

## 目录

- `frontend/`：队友 A 的前端代码。
- `database/`：队友 B 的 PostgreSQL 数据库代码。
- `research/`：队友 C 的需求分析 Markdown 与 PDF。
- `traces/`：四个节点的主题溯源卡片。
- `work-logs/`：四个节点的工作日志。
- `nodes/`：页面可读取的节点详情数据。
- `meta/`：角色代号、动态替换与接入说明。
