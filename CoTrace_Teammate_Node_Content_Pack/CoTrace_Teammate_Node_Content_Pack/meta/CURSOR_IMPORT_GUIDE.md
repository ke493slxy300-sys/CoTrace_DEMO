# Cursor 接入说明：队友节点详情

## 1. 页面定位

队友节点详情是“查看队友工作成果与判断依据”的只读页面，不是当前用户的个人编程 Agent 工作区。

页面主内容必须先展示代码仓或文档。AI 溯源卡片和工作日志用于解释产出背后的判断；团队讨论只通过按钮打开次级抽屉或弹窗，不能占据默认主布局。

## 2. 数据层次

| 内容 | 数据来源 | 默认展示 | 是否可编辑 |
|---|---|---|---|
| 代码/文档 | `frontend/`、`database/`、`research/` 或上一阶段后端包 | 主区域 | 队友查看态不可编辑 |
| 主题溯源卡片 | `traces/*.json` | 主区域中的辅助页签/区块 | 卡片标题可在拥有者工作区调整；查看态不可编辑 |
| 工作日志 | `work-logs/*.md` | 辅助页签/区块 | 查看态不可编辑 |
| 团队讨论 | 节点讨论数据 | 默认关闭的次级窗口 | 按权限发表评论 |

不要把“节点信息纯文本”做成左侧固定半屏，再把 AI 溯源与讨论塞进右侧。负责人、状态等元信息只应作为紧凑页头；代码仓或文档才是页面主体。

## 3. 代号动态替换

`队友 A / B / C` 只是 Demo 占位符，不是最终成员名称。

加载节点时：

1. 读取节点 `owner.resolveFromDuty`。
2. 在 `project.collaborators` 中查找匹配职责的成员。
3. 用真实的 `memberId / displayName / avatar` 替换占位信息。
4. 没有匹配成员时显示“待分配”。
5. 不得把 A/B/C 写入项目持久快照或上传记录。

## 4. 溯源卡片规则

- 只展示 `selectedByCurrentMember: true` 的卡片。
- `fragments` 是当前队友主动选中的短片段，不得扩展成完整聊天时间线。
- UI 要显示“由当前队友选取，项目理解 Agent 按任务主题整理”。
- 优先显示 `displayTitle`；`titleEdited: true` 表示成员改过 Agent 生成的标题。
- 卡片主体应区分：选中片段、人的理解、人的决定、影响产物、未决问题。
- “AI 建议”不能被渲染成最终决定；最终决定来自 `humanDecision`。

## 5. 工作日志规则

工作日志突出人的理解变化：初始理解、接受/调整/质疑/拒绝、决策对产出的影响、验证边界、未决风险和长期记忆候选。不要把日志压缩成“AI 做了什么”的流水账。

Maya 的日志来自此前个人协作记录的整理结果。本包刻意不重复原始对话；不要为填充页面而生成新的 Maya 原始消息。

## 6. 状态与导航限制

- 本包是节点演示内容，不注入 `submitted`、`approved` 或版本状态。
- 点击代码文件时在节点详情内部切换内容，不跳回个人工作区。
- “返回工作蓝图”回到蓝图并保留之前视口与选中节点。
- 团队讨论关闭后回到原代码/文档位置。
- 当前用户打开自己的待开始节点时，仍进入独立的个人编程 Agent 空白页；不要复用本页面。

## 7. 推荐组件边界

- `TeammateNodeHeader`：紧凑元信息和返回入口。
- `ArtifactViewer`：代码树/编辑器只读态，或 PDF/Markdown 文档查看态。
- `TraceCardList`：按主题展示当前队友选择的片段。
- `WorkLogPanel`：渲染人的判断记录。
- `TeamDiscussionDrawer`：次级窗口，默认关闭。

节点文件映射见 `nodes/*.json`，内容索引见 `meta/content-manifest.json`。
