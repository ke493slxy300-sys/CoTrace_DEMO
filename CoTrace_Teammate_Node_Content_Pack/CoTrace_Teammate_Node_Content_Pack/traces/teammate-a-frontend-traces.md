# 队友 A · 前端节点主题溯源

> 队友 A 是演示代号，实际页面应显示项目中承担前端职责的成员。本页只展示该成员主动选择的个人协作片段，并由项目理解 Agent 按主题整理；不是完整聊天记录。

## 稳定错误码需要转成可行动提示

- AI 片段：“前端不要直接展示后端 message；优先依赖稳定 code。”
- 当前队友片段：“可以，但每个提示要告诉用户下一步，尤其是商品已不可售。”
- 人的判断：集中维护错误码映射；未知错误统一兜底，不暴露服务端细节。

## 禁用按钮不是并发一致性的边界

- AI 片段：“请求期间禁用按钮并保存当前 Promise，可以减少双击。”
- 当前队友片段：“这只是体验保护；数据库仍要处理两个客户端同时购买。”
- 人的判断：前端承担体验保护，后端与数据库承担最终一致性。

## 成功结果展示下单快照

- AI 片段：“成功后继续读 item.title 可能与订单创建时不一致。”
- 当前队友片段：“结果卡直接消费接口返回的 title/price snapshot。”
- 人的判断：成功页进入订单上下文，只使用订单快照。

## 加载、失败与重试必须是同一状态机

- AI 片段：“可以用 idle / submitting / success / error 四态。”
- 当前队友片段：“失败后必须回到可操作状态，重试不能残留上一次错误。”
- 人的判断：使用单一 phase 驱动界面，避免多个布尔状态互相矛盾。
