# 队友 B · 数据库节点主题溯源

> 队友 B 是演示代号。以下是当前队友主动选择、由项目理解 Agent 归类的片段，不是完整对话。

## 订单快照隔离商品后续变化

- AI 片段：“订单只存 item_id，查询时关联 items 就能拿到标题和价格。”
- 当前队友片段：“历史订单不能随商品编辑而改变，标题、价格、币种都要快照。”
- 人的判断：交易历史的事实一致性高于结构上的完全规范化。

## 条件更新决定并发购买的唯一赢家

- AI 片段：“先 SELECT 状态，再 UPDATE 即可。”
- 当前队友片段：“检查与写入之间会竞争；直接 UPDATE ... WHERE status='available'。”
- 人的判断：以原子条件更新和受影响行数判断抢占结果。

## 商品锁定和订单写入必须共同回滚

- AI 片段：“更新商品后再插入订单，流程上已经连续。”
- 当前队友片段：“连续不等于原子；订单约束失败时商品必须恢复可售。”
- 人的判断：两个写操作必须处于同一事务。

## 暂不引入 reserved，但公开状态债务

- AI 片段：“等待卖家确认更适合增加 reserved 状态。”
- 当前队友片段：“判断成立，但本节点先不扩大迁移范围；必须把矛盾写清楚。”
- 人的判断：暂用 sold，同时记录原因、影响和退出条件。
