# Maya Chen · 后端 API 节点主题溯源

> 以下短片段由 Maya 从上一阶段个人 Agent 协作记录中选择，项目理解 Agent 负责归类与摘要。本包不复制完整原始对话。

## 接口可运行不等于业务边界完整

- AI 片段：“基础 create order 路由已经能返回订单。”
- Maya 片段：“先检查自购、商品不存在和不可售，否则只是路径跑通。”
- 人的判断：先枚举业务失败，再判断接口是否完成。

## 条件更新守住并发边界

- AI 片段：“先读取商品状态再更新，逻辑更直观。”
- Maya 片段：“两个请求会同时读到 available，必须让更新本身带状态条件。”
- 人的判断：应用层顺序不能替代原子数据操作。

## 订单响应必须携带不可变商品快照

- AI 片段：“返回 orderId 和 itemId 已足够，页面可继续用原商品对象。”
- Maya 片段：“成功态应该基于订单事实，标题和价格快照要进入响应。”
- 人的判断：创建接口应返回新领域对象的关键事实。

## sold 与待确认存在语义冲突

- AI 片段：“创建订单后把商品改成 sold，流程即可闭合。”
- Maya 片段：“页面还写等待卖家确认；sold 看起来像已经完成，必须公开这个矛盾。”
- 人的判断：本次不扩展 reserved，但不能隐藏状态债务。

## 测试通过不代表事务风险消失

- AI 片段：“现有测试均通过，可以认为创建订单功能完成。”
- Maya 片段：“这些测试替换了仓储层，还没证明真实数据库失败时会一起回滚。”
- 人的判断：单元测试结论需注明 Mock 边界；数据库集成测试仍是上线前阻塞项。
