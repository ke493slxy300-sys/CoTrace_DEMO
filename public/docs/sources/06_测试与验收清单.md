## 2. API 验收

- [ ] 成功响应为 HTTP 201；
- [ ] 买家身份来自登录会话；
- [ ] 所有业务错误返回稳定的 `code`；
- [ ] 未知错误不暴露堆栈；
- [ ] 返回的订单含 `itemSnapshot.title`；
- [ ] 返回的订单含 `itemSnapshot.price`；
- [ ] 订单状态为 `pending_seller_confirmation`。

## 3. 前后端联调验收

- [ ] 请求中操作键显示处理中并禁用；
- [ ] 成功后进入等待卖家确认页面；
- [ ] 自购错误显示正确中文提示；
- [ ] 商品不可售时刷新或退出详情；
- [ ] 服务错误后操作键恢复；
- [ ] 失败时不进入成功页面；
- [ ] 页面使用错误码而不是匹配错误消息。

## 4. 数据一致性验收

- [ ] 订单成功后商品不再接受新购买；
- [ ] 两个竞争请求最多一个成功；
- [ ] 订单标题和价格不随商品后续修改；
- [ ] 订单写入失败时商品尝试恢复；
- [ ] 真实数据库接入前保留事务风险说明。

## 5. CoTrace 协作验收

- [ ] 个人工作区显示完整 Agent 原始对话；
- [ ] 队友节点只显示已提交代码；
- [ ] 队友节点只显示负责人选择公开的 AI 溯源；
- [ ] 被拒绝或未公开的对话不出现在队友页面；
- [ ] AI 溯源可以关联到相应文件；
- [ ] 团队讨论作为次级窗口打开；
- [ ] 打开讨论后保留当前文件和代码阅读位置。

## 6. 未覆盖风险

- 真实数据库事务中断；
- 多进程并发；
- 重复请求保护；
- 卖家拒绝与商品恢复；
- 订单取消和超时；
- 支付、退款与争议处理。

以上内容应进入后续任务，不应被标记为当前版本已完成。
