# 《软件工程》核心课程作业要求

课程：软件工程  
项目：《校园二手交易平台》

## 1. 作业目标

以小组协作方式完成一个可演示的校园二手交易系统，覆盖发布、浏览、咨询、购买到评价的主路径，并体现需求、设计、实现、联调与验收过程。

## 2. 功能范围（最低要求）

- 发布商品（教材 / 实验器材等）
- 浏览与筛选商品
- 查看商品详情
- 发起咨询
- 提交购买申请
- 卖家确认 / 买家确认收货
- 评价或举报（可简化）

## 3. 技术与协作要求

- 前后端分离或等价分层清晰。
- 订单需保存交易时的商品标题与价格快照。
- 关键错误（商品不存在、不可购买等）需返回可区分的错误信息。
- 团队需保留任务分工、关键讨论与验收依据。

## 4. 验收要点

- 主路径可现场演示。
- 关键状态流转正确。
- 有可复查的代码、文档或测试记录。
- AI 仅作辅助，不得替代人类决策与最终确认。
