# AI 共识协议（人机协作约定）

适用范围：CoTrace 课程项目《校园二手交易平台》演示。

## 1. AI 角色

- AI 仅提供建议、整理上下文与风险提示。
- AI 不拥有审批权，不能自动修改任务状态或责任归属。
- 所有对外产出必须经过人类负责人确认。

## 2. 人类角色

- 项目负责人（Maya Chen）对后端 API 与整体验收负责。
- 协作成员对各自职责范围内的设计与实现负责。
- 技术判断、讨论结论与最终决定必须由团队作出。

## 3. 协作记录

- 重要决策应保留依据：任务节点、代码范围、讨论与验证记录。
- 提交代码产出时需说明 AI 如何参与及待审查问题。
