## 体验者操作应产生的变化

1. 体验者在个人工作区编辑代码：只改变私人草稿，节点详情不变。
2. 体验者确认提交：选中代码和溯源进入节点公开快照，未选内容保持私密。
3. 体验者确认任务完成：只改变蓝图任务状态，不额外公开内容。
4. 体验者回复讨论：消息进入团队讨论，但不会自动形成团队决定。
5. 体验者确认归档：讨论结束，Agent 生成决定草案。
6. 体验者确认决定草案：该决定才具备进入项目日志的资格。

## 当前风险

- 现有静态内容、localStorage 和新 Store 之间可能产生双数据源。
- 提交、完成、讨论归档和决定确认容易被错误合并成一个状态。
- 如果项目日志直接读取私人工作区，会破坏 CoTrace 的公开边界。
- 后续实现必须使用真实 projectId、nodeId 和 memberId，不能根据显示姓名判断。
