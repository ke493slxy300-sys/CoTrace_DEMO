# 角色分工与人工审查说明

项目：《校园二手交易平台》

## 1. 角色分工（演示预置）

- Maya Chen：项目负责人、后端 API
- 数据库设计 / 前端页面 / 测试验收 / 交易联调 / 产品分析：由注册时选定的协作者承担

## 2. 人工审查原则

- AI 生成的接口草案、错误码建议与文案，须由对应负责人审查后才能作为团队约定。
- 代码提交前应说明：改了什么、AI 如何参与、仍待审查的问题。
- 蓝图状态仅在正式提交产出后更新，编辑草稿不改变蓝图。

## 3. 建议审查清单

- 错误码是否与前端提示一致（如 LISTING_NOT_FOUND / LISTING_UNAVAILABLE）
- 订单快照字段是否完整
- 联调主路径是否可演示
- 验收标准是否可核对
